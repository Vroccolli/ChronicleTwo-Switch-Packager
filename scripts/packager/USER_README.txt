ChronicleTwo Switch Packager - Windows x64 preview

1. Extract the entire ZIP to a normal folder. Keep _internal beside the EXE.
2. Open ChronicleTwo-Switch-Packager.exe.
3. Select your European PAL Dark Chronicle ISO and an output folder.
4. Click Create Switch folder. Keep the window open until it finishes.
5. Copy the resulting switch folder to the root of your Switch SD card.
6. Launch ChronicleTwo in full-application homebrew mode.

No Python, compiler, SDK, internet connection or PC game installation is needed.
Allow 12 GiB free on the output drive. Conversion can take 15 minutes or longer.
The input ISO is read only. Original game data is not included in this package.
The US Dark Cloud 2 ISO and modified disc images are not supported by this build.
An existing ChronicleTwo-PC-Switch installation is never overwritten. Choose a
fresh output directory and back up saves before manually updating an SD card.

This is the native ChronicleTwo engine, using recovered game source and the
original MainLoop. It is a preview with ongoing performance/compatibility work.
The bundled executable is checked against its complete-engine build report;
that does not certify full campaign completion or hardware testing of this build.
The output installation.json records version, hashes and hardware-test status.

On failure, the error identifies an unfinished folder containing packager.log.
It is safe to remove that specific unfinished folder after closing the app.
Do not rename an unfinished folder into an installation.
